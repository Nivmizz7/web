# Nivmizz7 Portfolio

Portfolio website for Nivmizz7 - Back-end Web Developer & Server Management

## 🚀 Project Setup

This project is now set up as an NPM project with Vite as the build tool.

### Installation

```bash
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

The site will open at `http://localhost:5173`

### Build

Build for production:

```bash
npm run build
```

The output will be in the `dist/` folder.

### Preview Build

Preview the production build locally:

```bash
npm run preview
```

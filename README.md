## Tech Stack

| Frontend | Backend | Design |
|----------|---------|--------|
| HTML5 | Node.js | Glassmorphism |
| CSS3 | Express 4 | Google Fonts (Outfit + Poppins) |
| JS (ES6) | — | Font Awesome 6 + Devicon |


## Setup

```bash
git clone https://github.com/Nivmizz7/web.git
cd web
npm install
npm start
```

Server runs on `http://localhost:3000` by default. Set `PORT` env to change.
